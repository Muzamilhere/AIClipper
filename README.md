# 🎬 AIClipper — AI Viral Video Generator (OpusClip Style)

AIClipper is an AI-powered video automation system that converts long-form videos into short, viral-ready clips for TikTok, Instagram Reels, and YouTube Shorts.

It automatically detects engaging moments, generates subtitles, and exports polished vertical videos.

---

## 🚀 Key Features

- 🧠 AI-powered viral moment detection
- ✂️ Automatic video clipping (FFmpeg engine)
- 🎤 Whisper-based speech-to-text
- 📝 Auto subtitle generation (.SRT)
- 🎬 TikTok-style animated captions
- 📱 Vertical video output (9:16 ready)
- ⚡ Fully automated pipeline

---

## 🧠 How It Works

1. Extract audio from video
2. Transcribe speech using Whisper AI
3. Analyze transcript for engaging moments
4. Cut video into short clips
5. Generate subtitles
6. Burn TikTok-style captions

---

## 🏗️ Tech Stack

- Python
- MoviePy
- FFmpeg
- Whisper / Faster Whisper
- OpenCV (future upgrade)
